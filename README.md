## 📌 Tentang Proyek

**LCD Store** adalah platform web e-commerce berbasis **Laravel 11** khusus penjualan suku cadang layar (LCD) untuk berbagai merek smartphone Android (Samsung, Xiaomi, Oppo, Vivo, Infinix, dll.) maupun Apple iPhone. 

Keunggulan utama platform ini adalah fleksibilitas opsi pemesanan, di mana pelanggan dapat memilih antara membeli sparepart unit saja atau sekaligus menggunakan layanan teknisi untuk pemasangan layar.

---

## ✨ Fitur Utama

- 🛍️ **Dua Mode Pembelian**:
  - **Beli LCD Saja**: Sparepart dikirim langsung ke alamat customer.
  - **LCD + Jasa Pasang**: Layanan perbaikan layar oleh teknisi profesional.
- 🔐 **Multi-Role Authentication**:
  - **Admin**: Dashboard statistik omzet, manajemen produk LCD (CRUD & stok), dan kontrol status order.
  - **Customer**: Registrasi akun, filter produk (OS & Brand), checkout pesanan, dan pemantauan riwayat belanja.
- 🎨 **Modern & Vibrant UI**:
  - Antarmuka bertema cerah (*cyan & emerald tone*) dengan styling utility-first menggunakan Tailwind CSS.
  - Responsif dan nyaman digunakan di perangkat desktop maupun smartphone.
- 🔍 **Filter & Pencarian**:
  - Navigasi cepat berdasarkan platform (Apple iPhone vs Android) dan pencarian instan nama tipe perangkat.

---

## 🛠️ Stack Teknologi

- **Backend Framework:** [Laravel 11](https://laravel.com/)
- **Bahasa Pemrograman:** PHP >= 8.2
- **Database:** MySQL
- **Frontend / Styling:** Blade Templating + Tailwind CSS
- **Icons & Fonts:** FontAwesome 6 & Google Fonts (*Plus Jakarta Sans*)
